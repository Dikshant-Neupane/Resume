# PROJECT BRIEF: MANDALA BOOK PORTFOLIO

## Core Philosophy
- Craftsmanship over decoration
- Narrative structure over random layout
- Purposeful animation over spectacle
- Accessibility without compromise

## Technical Stack
- HTML5, CSS3 (3D Transforms), Vanilla JS, SVG

## Design System
- **Colors:** Paper (#F8F6F1), Ink (#2C2C2C), Accent (#8B7355), Mandala (#C4A57B)
- **Typography:** Playfair Display (Heading), Inter (Body), Crimson Text (Accent)
- **Layout:** 16:10 Aspect Ratio, Two-page spread

## Animation System
- 3D Book Open (2.5s)
- Page Flip (0.9s)
- Mandala Stroke Drawing (1.5s)

## Structural Architecture
- Book Container -> Book -> Pages (Mandala, Hero, About, Skills, Projects, Experience, Contact)
- Bookmark Navigation
- Command Menu (Cmd+K)
